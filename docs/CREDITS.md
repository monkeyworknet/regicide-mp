## Required attributions (in-app Credits screen + this file)

- **Dicier** typeface (Speak the Sky, CC BY 4.0) is **not bundled** in this build. It is kept as an
  option for a future pass; if reintroduced, re-add the attribution above the provenance table.
- **Crisp Cards — Free Sampler** sound effects, from <https://anipixels.itch.io/crisp-cards>. Embedded in
  this game only; the sample pack itself is not redistributed as a pack.
- **Regicide** © Badgers from Mars. **Designer:** Andy Richdale, Luke Badger and Paul Abrahams.
  **Artist:** D.J. Phillips. **Publisher:** Badgers from Mars. This is an unofficial,
  non-commercial fan implementation of the published rules. The published deck's card art is
  credited in the app as Sketchgoblin (the art supplied for this build).
  The **Official** card set is the published deck's art, cut from the publisher's uncut sheet, used
  here for a non-commercial fan build; it is not redistributed as a printable deck.
- **Pokémon** © Nintendo / Game Freak / Creatures Inc. The "RageIced" card sheets are a fan re-theme by
  Wil Su (v2023-04-25); the sheets state personal, non-commercial use only and redistribution only if
  unmodified.
- **Regicide rulebook** text (`docs/research/rules-raw.txt`) — quoted for rule verification only.
- **Material Design Icons** (Apache 2.0, Pictogrammers): the table reveal's crossed-swords
  (`sword-cross`) and shield (`shield`) glyphs are embedded as SVG paths in `web/app.js`.
  No icon font or image file is committed.

## Fan-asset rule

This is an unofficial, non-commercial fan build: nothing here is sold, and no rights in the game,
its name, its rules or its art are claimed. The Pokémon re-theme is the most constrained asset in
the tree — its source sheets allow personal, non-commercial use only. Deleting `web/img/pokemon/`,
the `pokemon` entry in `web/data/themes.json` and its rows here leaves a build made only of
original art and the published deck's own cards.
